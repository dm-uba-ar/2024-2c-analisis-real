### Para cursar la materia

- Para poder ser incluido
  en las actas de trabajos prácticos es necesario haberse inscripto mediante
  el [SIU Guaraní](https://inscripciones.exactas.uba.ar/exactas/). Además para poder figurar como aprobado es obligatorio completar la encuesta de evaluación docente.
- Para cursar es necesario tener aprobados los trabajos prácticos de
  Probabilidades y Estadística y el final de Cálculo Avanzado.
